## 🛠️ Requirements

To compile and run these programs, you need:

- A C++ compiler, such as **GCC** or **Clang**
- Support for the **C++17** standard
- A terminal or command-line interface
- A code editor such as Visual Studio Code (optional)

## 🚀 Getting Started

### 1. Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/imahalakshmi12/20-cpp-programs.git
```

Navigate into the project directory:

```bash
cd 20-cpp-programs
```

### 2. Choose a Program

Select any `.cpp` file you want to run.

For example:

```text
02_addition.cpp
```

### 3. Compile the Program

If you have GCC installed, use:

```bash
g++ -std=c++17 02_addition.cpp -o addition
```

Alternatively, if you use Clang:

```bash
clang++ -std=c++17 02_addition.cpp -o addition
```

### 4. Run the Program

On macOS or Linux:

```bash
./addition
```

On Windows:

```bash
addition.exe
```

**Note:** Replace `02_addition.cpp` with the filename of the program you want to compile. The output filename can also be changed as needed.
